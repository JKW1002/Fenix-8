# Design mockups

Mockups considered for v1.0.1. **Option C was built as v1.0.1.**

- `option-a-no-bezel.png`: the on-screen dive bezel removed, wave dial and minute track run to the screen edge.
- `option-b-no-bezel-no-batons-larger-dials.png`: as option A, plus the baton hour markers removed and the three small dials made about a third larger.
- `option-b-source.html`: the drawing used to make option B, to regenerate the dial image when it is built.
- `option-c-larger-dials.png`: as option B, with the small dials made larger again (radius 64 instead of 54, set 116 px from centre). **Built as v1.0.1.**
- `option-c-source.html`: the drawing used to make option C.
