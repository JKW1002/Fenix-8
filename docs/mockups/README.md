# Proposed design changes (not built yet)

The live watch face (v1.0.0) is unchanged. These are mockups for a possible v1.0.1, on hold while the current version is tested for about a week.

- `option-a-no-bezel.png`: the on-screen dive bezel removed, wave dial and minute track run to the screen edge.
- `option-b-no-bezel-no-batons-larger-dials.png`: as option A, plus the baton hour markers removed and the three small dials made about a third larger. **This is the preferred option.**
- `option-b-source.html`: the drawing used to make option B, to regenerate the dial image when it is built.
